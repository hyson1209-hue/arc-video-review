# ARC 운영절차서 — 영상 아카이브 & 검수

## 검수 흐름

```
영상 업로드 (대시보드 → 업로드, 복수 가능)
    ↓
자동 분석 — 병렬 실행
  · 언어: 자막 추출(내장 트랙 → 없으면 음성 인식) → AI 교정
  · 분석: 장면 분석 ∥ 기술 검토(무음/블랙/프리즈) → 색인 생성
  · 검수: 프레임 샘플링(약 1초 간격) → 금칙 판정(연속 2~3장 묶음 + 대사·소리 근거) → 종합 판정
    ↓
처리 완료 → 텔레그램 알림
    ↓
검색(4모드) 또는 검수 리포트 확인
```

- **한 단계가 실패해도 나머지 단계는 계속 진행된다.** 실패 단계는 업로드 화면과 알림에 표시된다.
- 프레임 판정 실패 시 해당 묶음은 `정상` 처리 후 계속 진행된다.

## 판정 기준 변경

`server/rules/금칙기준.md` 를 수정하면 **다음 영상부터 즉시 적용**된다. 서버 재시작·코드 수정 불필요.

예) "속옷 노출 = 주의(1~2)" 기준 때문에 탈의 영상이 '검토 필요'에 그친다면,
기준에 "의도적 탈의·성적 어필 = 4(방영 불가)" 를 명시 → 같은 영상이 '방영 불가'로 판정된다.

## 판정 등급

| 점수 | 판정 | 후속 조치 |
|------|------|----------|
| 0 | 통과 | 방영 가능 |
| 1–2 | 주의 | 편성 시간대 검토 |
| 3 | 경고(검토필요) | **담당자가 반드시 직접 확인** |
| 4–5 | 방영 불가 | 방영 금지, 수정 후 재검수 |

모호한 장면은 자동 통과 없이 3(검토필요)으로 분류된다.

## 산출물

| 파일 | 위치 | 내용 |
|------|------|------|
| `report.json` | 리포트 화면 다운로드 버튼 | 프레임별 + 종합 판정 결과 |
| `violations.csv` | 리포트 화면 다운로드 버튼 | 위반 목록 (t, 카테고리, 점수, 판정, 사유) |
| 위반 프레임 JPEG | 리포트 화면에서 직접 확인 | 판정에 사용한 연속 묶음 프레임 |

## 삭제

- 대시보드 또는 리포트에서 삭제 가능. **원본 + 리포트 + 검색 색인 + 프레임이 모두 영구 삭제**된다.
- 처리 중인 영상은 삭제할 수 없다 (완료 후 삭제).

## 데이터 위치

- DB: `server/data/arc.db` (키워드 FTS5 + 벡터 임베딩 병행, 재시작 후 유지)
- 원본: `server/data/uploads/<영상ID>/`
- 프레임: `server/data/frames/<영상ID>/`
